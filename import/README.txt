PokeDoom -- import folder

This folder is where PokeDoom reads the real DOOM files you supply --
this mod ships none of id Software's or GZDoom's own data.

DOOM WAD (required for PKDOOM MODE):
  Place your own legally-owned DOOM WAD file here -- doom.wad,
  doom1.wad, doom2.wad, tnt.wad, plutonia.wad, a Freedoom IWAD, or any
  other real DOOM IWAD. Any filename ending in .wad is fine.
  Then, in-game: open the PKDOOM MODE settings menu and press
  "IMPORT DOOM WAD."

GZDoom BigUpper font (optional, cosmetic only):
  Copy game_support.pk3 itself -- the whole file, no extraction needed
  -- from your own GZDoom install (it sits next to gzdoom.exe) into this
  same folder. Then, in-game, press "IMPORT GZDOOM FONT." PKDOOM MODE
  works fine without this; it only affects the menu font's look.

(This file exists so the "import" folder itself ships with the mod --
delete or ignore it, it isn't read by anything.)
